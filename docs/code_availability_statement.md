# Code Availability Statement

Manuscript-ready wording for the public code release:

The MiniCpG source code, trained 30-CpG model, final CpG panel, aggregate source data for manuscript figures and supplementary tables, and reproduction documentation are available for academic and non-commercial research use at https://github.com/talgutman/MiniCpG under the MiniCpG Academic and Non-commercial Research Use License. Raw methylation matrices, sample-level metadata, and sample-level prediction outputs are not redistributed; users should obtain TCGA, GEO, ArrayExpress, and other public inputs from the original repositories under the applicable data-use terms.

Shorter version:

Code, the trained MiniCpG model, the final 30-CpG panel, and aggregate reproduction files are available for academic and non-commercial research use at https://github.com/talgutman/MiniCpG. Raw methylation matrices and sample-level metadata are not redistributed and should be obtained from the original public repositories under their applicable data-use terms.
