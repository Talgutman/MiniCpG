# Supplementary results

The [table index](revision_20261119/README.md) provides machine-readable data for Supplementary Tables S1–S27. Each table is split into its constituent TSV blocks, with titles in `tables.json` and checksums in `manifest.tsv`.

The exports contain aggregate results. Specimen-level measurements, clinical annotations and predictions are obtained or generated separately using the [analysis workflows](../docs/workflows.md).
