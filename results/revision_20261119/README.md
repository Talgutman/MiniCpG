# Revised supplementary aggregate data

Machine-readable source values for Tables S1–S25 in the November 2026 author-review manuscript. Each table block is a TSV; `tables.json` supplies titles, headers/notes and block mapping. Values retain source precision and can differ from rounded manuscript displays. Blank values remain unavailable, not zero.

The tables were exported from the numerically validated authoring records. All fourteen current analytical workbook hashes matched those records. Subsequent S6/S24 edits moved procedural text into Supplementary Methods while preserving numerical content; the manuscript remains authoritative for current wording and references. These exports do not include specimen-level measurements, identifiers or predictions. Historical July results remain available through the unchanged v0.1.0 tag and are excluded from this tree.

`manifest.tsv` records export hashes and source-record hashes. This is a frozen aggregate export, not a claim that every underlying analysis was rerun. Reproduction requires obtaining permitted inputs and following the analysis recipes.
